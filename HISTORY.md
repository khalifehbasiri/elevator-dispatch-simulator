# Historical snapshots

Related project files and saved edits from the same recorded day are grouped into one snapshot. A later day with changed content receives another snapshot; repeated same-day saves and unchanged snapshots are consolidated.

This is a retrospective import using preserved project dates. The dates describe the recorded versions rather than when they were uploaded to GitHub. Both Git timestamps use the latest recorded timestamp in the daily snapshot. Documentation about this import is maintained on its actual maintenance date.

The final project source is unchanged by consolidation. Earlier detailed recovery evidence and the previous Git history are backed up locally. Existing contributor credits remain intact.
