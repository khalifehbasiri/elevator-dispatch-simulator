# Elevator dispatch simulator

Qt desktop simulation with configurable floors, elevators and passengers, nearest-car dispatch, queued requests, and fire/overload/stop states.

This is the preserved source baseline. Presentation improvements and build/workflow checks are queued after the historical uploads. The repository stays private until that work and the public-content review are complete.

## Contents

The repository contains the original C++ model and supporting source files. The photo catalog includes synthetic ASCII fixtures. An executable reservation demonstration is queued separately.
